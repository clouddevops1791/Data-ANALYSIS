# Data-ANALYSIS

This README provides a concise overview of the 365 Corporation Performance Dashboard, a comprehensive business intelligence tool designed to analyze sales, product trends, and customer demographics from 2010 to 2014.

📊 Project Overview
This dashboard serves as a high-level executive summary, transforming raw transactional data into actionable insights. It tracks key performance indicators (KPIs) across global markets to support data-driven decision-making.

Key Metrics & Insights
Financial Health: Monitoring $43.5M in Total Sales with a healthy 42.4% Gross Profit Margin.

Operational Volume: Tracking 89.8K units sold, led primarily by the "Bikes" and "Accessories" categories.

Market Analysis: Visualizing geographic performance, with the United States and Australia emerging as top revenue drivers.

Seasonality: Identifying monthly fluctuations in sales, production costs, and profit to optimize inventory and marketing spend.

🛠️ Tech Stack
Data Visualization: Power BI ,SQL

Data Source: 365 Corporation Sales & Customer Records FROM A DATA WAREHOUSE CREATED WITH SQL IN A PREVIOUS PROJECT IN THIS PORTFOLIO (DATAWAREHOUSEING PROJECT WITH SQL)

Features: Interactive slicers (Country, Gender, Category), Time-series analysis, and Geospatial mapping.
